# COLAB

Plataforma colaborativa para proyectos en equipo.

## Descripción

COLAB es una plataforma diseñada para facilitar la colaboración entre desarrolladores y equipos de trabajo.

## Características

- ✅ Gestión de proyectos
- ✅ Colaboración en tiempo real
- ✅ Versionado de código
- ✅ Comentarios y discusiones
- ✅ Integración con Git
- ✅ Dashboard de actividad

## Requisitos

- Node.js 18+
- npm o yarn
- MongoDB 5.0+
- Redis 6.0+

## Instalación

```bash
git clone https://github.com/jacxas/COLAB.git
cd COLAB
npm install
npm run dev
```

Accede a: http://localhost:3000

## Scripts

- `npm run dev` - Desarrollo
- `npm run build` - Compilar
- `npm run start` - Producción
- `npm run test` - Tests
